### 👋 Sobre mim

- 🤖 Faço **bots de Telegram**, scrapers e automações que resolvem problemas do dia a dia
- 🌐 Contribuo com a **Web Crypto API** do [Lightpanda](https://github.com/lightpanda-io/browser), um browser headless escrito em Zig
- 🎮 Ajudo a portar bibliotecas do PS5 para Windows e Linux no [AnyPS5](https://github.com/boykopovar/AnyPS5)
- 🛠️ No dia a dia: TypeScript, Python, Cloudflare Workers e o que mais o problema pedir
